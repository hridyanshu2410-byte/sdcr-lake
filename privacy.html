Privacy policy

sdcr-lake. Effective October 7, 2026.

sdcr-lake is a single-user research tool. This policy describes what it does with information when its operator signs in with a Google account.

Information the tool accesses

With the operator's permission, granted through Google's OAuth consent screen, the tool uses the Google Drive API to create, update, list and read the dataset files it stores in a dedicated folder of the operator's Drive. It also receives the access and refresh tokens Google issues for that permission.

How the information is used

The information is used only to store and organize copies of public datasets for the operator's research. The tool does not use Google user data for advertising, does not sell it, and does not transfer it to anyone else. The datasets themselves are public records published by government agencies and contain no information about the person signing in.

Storage and security

OAuth tokens are kept only in a configuration file on the operator's own computer. They are not stored on any server operated for this tool, not published, and not shared.

Limited use

The tool's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time from the Google Account permissions page at myaccount.google.com/permissions. Revoking access stops the tool from reaching Drive. Files the tool already stored remain in the operator's Drive until the operator deletes them.

Changes and contact

If this policy changes, the effective date above will be updated. Questions can be sent to hridyanshu.2410@gmail.com.
